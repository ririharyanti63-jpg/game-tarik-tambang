# Battle Tarik Tambang - IPAS (Ekosistem)

Game edukasi interaktif berbasis web dengan tema **Tarik Tambang** untuk pembelajaran materi **Ekosistem (IPAS)** bergaya visual Minecraft.

## Fitur Permainan
- **Mode 2 Tim (Tim Merah vs Tim Biru)**: Nama tim dapat disesuaikan.
- **50+ Soal Ekosistem**: Pertanyaan seputar komponen biotik/abiotik, rantai makanan, simbiosis, dan pelestarian lingkungan.
- **Tarik Tambang Dinamis**: Posisi tali bergeser ke arah tim yang menjawab dengan benar dan unggul poin.
- **Audio & Musik Chiptune**: Efek suara sintetis retro (Web Audio API) yang dapat dinyalakan/dimatikan.
- **Batas Waktu Ronde**: Timer 20 detik per ronde untuk memacu kecepatan dan ketepatan berpikir.

## Cara Menjalankan
Cukup buka file `index.html` di browser modern (Google Chrome, Microsoft Edge, Mozilla Firefox, dsb.) tanpa perlu instalasi tambahan.

## Teknologi
- HTML5
- CSS3 (Responsive Design & Pixel-art inspired style)
- Vanilla JavaScript (Web Audio API)
